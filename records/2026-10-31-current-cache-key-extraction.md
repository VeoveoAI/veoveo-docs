## What changed in the proof input

The prior graph represented Core's `PrincipalId` and `ServerSlug` with handwritten
nominal-value models and primitive clone/comparison definitions. The new extraction
includes their actual String-backed types and derives, as well as SDK `LinkName`.
It retains all five key fields, both lazy callback bodies and the actual SDK TTL
initializer. There are five roots, 36 explicit includes and no explicit opaques.
All 37 discovered Hub/SDK/Core function bodies are transparent, present and without
extraction errors. This removes the need to assume the identifier wrappers' own
operations; standard String representation/ordering remains an external boundary.

The first attempt stopped at offline Cargo metadata in 116 ms because the pinned
Lore checkout was absent; no translator ran. A bounded `cargo fetch --locked`
succeeded in 3.971 s, fetching exact Lore `c33e017af48d221c5b42d19865adf78814bcced4`.
All 1,144 source files and `Cargo.lock` remained unchanged. A fresh second directory
preserves the failed attempt rather than overwriting it.

The second attempt's metadata and target preparation took 315 and 164 ms. Charon
completed in **47.303 s**, then Aeneas in **1.169 s**; all exited zero without a
timeout. The LLBC is **1,388,012 bytes**, SHA-256
`e8a70973f988a3b1ca09fb153bdf43c16422cbf5b6248c7c6b556ee8419871aa`.
It contains 174 function declarations, 38 types, 17 traits, 93 implementations and

## Remaining boundary

Lean must now check the full clone/comparison/ordering, exact operation contracts,
state invariants and histories against these new outputs. The planned cross-link
theorem connects actual full-key invalidation to preserving another link's entire
cached value, ticket and retry record, including absent versus present link names.
It makes no general cross-key write-isolation claim: capacity eviction can remove
the minimum other key.

The pinned extraction compiler also reported an unrelated async `MaybeSendFuture`
recursion-depth warning, an unreachable call in the MCP App code, and OpenShell
future-incompatibility notices. No affected async code is a selected root. The
five-root LLBC has no errors; this does not establish a whole-crate translation.
Server-wide invalidation, pagination, native key construction/fingerprinting and
async listener behavior remain outside this graph. No source, pin, tool or backend
change, native test rerun, deployment or model call was part of this checkpoint.
