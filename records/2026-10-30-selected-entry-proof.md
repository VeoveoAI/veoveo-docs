## Contract and implementation boundary

`selected_entry_exact` connects the unchanged generated `selected` closure to the
independent `chooseOne` specification. It uses the already checked keyed lookup
contract, then establishes the actual server-name comparison and clone result.
Four named corollaries expose unavailable, missing, wrong-slug and successful
matching cases. The universal theorem needs no well-formed-map, unique-key,
desired-route, namespace-helper or issuer premise.

The emitted key is the requested deployment. Equality to the row's own deployment
field remains a constructor-coherence obligation; no extra runtime check was added.
Native collections, equality, cloning and compiler/translator correspondence remain
explicit boundaries. Full iterator collection and output uniqueness are not proved
by the entry theorem.

The generated callback captures a pair through a semireducible type alias. A
private proof lemma exposes its exact pair destructuring and clone operation under
an explicit tuple type. `with_unfolding_all rfl` lets Lean check that equality by
kernel conversion. Later reasoning simplifies the existing clone model. No raw
generated bytes, primitive model, reducibility attributes or axioms were changed.
