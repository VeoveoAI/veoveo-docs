# n8n 2.48.7 on Node.js 26.13.1

2026-11-20. n8n published 2.48.6 and 2.48.7 while the 2026-11-18 fork sync
([2026-11-19-fork-sync.md](2026-11-19-fork-sync.md)) was being deployed. The fork moved to 2.48.7, its image
moved to Node.js 26.13.1, and the installation's Computer and n8n runners took both.

Coordinator Claude Opus 5.5 in Claude Code, no worker agents. Builds, checks and deployment ran as unattended
scripts on the box (`~/k3s-builds/sync-20261120/`) and the Mac.

## Upstream

- **Releases:** 2.48.6 (2026-11-19) and 2.48.7 (2026-11-20) are the latest stable; 2.49.3 is a prerelease.
  Over 2.48.5 they bring the v3 migration rules' "How to fix" steps, the memory guard's hold ending when a
  stop frees no memory, plain input data in scripting nodes' error output, and the patched Node image pin. No
  dependency, lockfile or database migration changes.
- **Upstream's Node:** 2.48.6 builds on `n8nio/node-patched:26.13.0-6484e2d8…` (#44351): Node 26.13.0
  compiled by n8n with pointer compression off and one V8 patch (two-byte array-index strings in the AST
  value factory), on an Alpine base. Upstream master pins the same 26.13.0.
- **Node 26.13.1** (2026-11-11) is Node's security release: seven High CVEs in TLS and HTTP/2, among them a
  remotely reachable TLS server crash, plus Medium and Low ones. The 2026-11-18 image was built on 26.13.0
  after it was out, and missed it.
