# Records

Dated plans, execution logs and qualification evidence. They describe what was
decided, done and measured at the time; they are not the current design. The current
design is in [ARCHITECTURE.md](../ARCHITECTURE.md) and the `DESIGN.md` files it maps,
and current status is in [PLAN.md](../PLAN.md) and the
[qualification checklist](../QUALIFICATION_CHECKLIST.md).

Reports cite records for evidence. Each new piece of work adds one dated file here,
named `YYYY-MM-DD-topic.md`; existing records are not rewritten.
